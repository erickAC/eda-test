### **Event Sourcing**
Repositório de estudo de montagem de uma arquitetura event-driven.

#### Tecnologias utilizadas
- Spring Boot
- Spring Data JPA
- Spring AMQP
- RabbitMQ
- PostgreSQL
- Kong Gateway

#### Iniciando
Para executar primeiro, temos que rodar o compose em /stock

Após isso podemos rodar o ```docker compose up -d```.
